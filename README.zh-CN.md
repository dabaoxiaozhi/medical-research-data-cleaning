# 医学科研数据清洗 Skill

本仓库包含一个疾病无关的 Codex skill，用于回顾性医学科研数据在统计分析或机器学习建模前的数据清洗与特征工程。

可安装的 skill 文件夹是：

```text
medical-research-data-cleaning/
```

## 适用范围

该 skill 适合处理临床、检验、登记研究、电子病历等医学科研数据，尤其适合以下任务：

- 原始数据保护与可重复清洗流程设计。
- 总体数据质量分析。
- 变量分类与建模前变量管理。
- 检测限结果解析，例如低于检测下限或高于检测上限的结果。
- 有临床意义的“未检测即可能正常/低风险”缺失模式处理。
- 同一医学概念的多来源变量合并。
- 按训练集拟合、验证集应用的缺失插补、异常值处理、编码和标准化。
- 生成树模型版和线性模型版的模型就绪数据。
- 生成审计报告、工作记录和论文方法学文字。

## 不包含的内容

本 skill 是通用方法包，不包含任何具体项目的隐私信息或变量信息。

请不要在本仓库中发布：

- 患者级数据。
- 原始数据或清洗后数据。
- 医院、科室或研究中心身份信息。
- 私有变量清单。
- 项目特异的结局变量定义。
- 真实数据字典或可反推出数据来源的字段说明。

如需举例，请使用合成数据或完全匿名化的示例字段。

## 与不同智能体的兼容性

该项目的核心 skill 文件是 Codex skill 格式：

```text
medical-research-data-cleaning/SKILL.md
```

在 Codex 中，它可以作为 skill 被自动发现和调用。其他智能体或工具的兼容性取决于它们是否支持读取 `SKILL.md` 或类似的本地技能/规则文件。

- **Codex**：可按 Codex skill 规范直接使用。
- **OpenCode、Hermes 或其他智能体**：通常不能保证“原生自动调用”，但可以把 `SKILL.md` 和 `references/` 作为提示词规则、项目说明或 agent instructions 读取使用。
- **通用大模型助手**：可以手动粘贴 `SKILL.md` 内容，或把本仓库作为上下文文件提供给模型。

因此，本仓库可以被其他智能体复用，但自动触发、安装路径和元数据识别方式需要按对应智能体的规则适配。

## 本地安装到 Codex

将内层 skill 文件夹复制到 Codex skills 目录：

```powershell
Copy-Item -Recurse .\medical-research-data-cleaning $env:USERPROFILE\.codex\skills\
```

然后重启或刷新 Codex，使其重新发现 skill 元数据。


- `scripts/` 保存可复用的验证脚本。

## 推荐使用流程

1. 先保护原始数据，只读取原始文件，不覆盖原始文件。
2. 生成总体数据质量报告。
3. 制定变量分类规则。
4. 先做规则型清洗，例如检测限转换、定性变量编码、同概念变量合并。
5. 再进行训练集/验证集划分。
6. 只在训练集上拟合插补值、编码器、标准化器和异常值规则。
7. 将训练集拟合得到的规则应用到验证集。
8. 生成模型就绪数据、审计报告和论文方法学描述。
